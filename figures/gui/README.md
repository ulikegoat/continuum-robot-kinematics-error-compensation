# Dashboard screenshots

No application screenshot is checked in yet. The GUI must be launched and captured manually; scientific figures elsewhere in the repository are not GUI screenshots.

Use the dashboard's **Capture** button or `Ctrl+Shift+S` and save actual application-only PNG files here. The capture composites the OpenGL framebuffer into the window image. **Save 3D viewport PNG** exports just the OpenGL scene. Suggested manual sequence and filenames:

1. **Robot** workspace, bent preset, **Focus robot** → `synthetic_comparison.png`.
2. **Compensation** workspace, random experiment, **Light** cloud, **Focus robot** → `dashboard_overview.png`.
3. **Measurements** workspace, **Full** cloud, **Fit workspace** → `physical_workspace.png`.
4. **Analysis** workspace, select the desired Phase 6 v2 protocol → `phase6_model_comparison.png`.

Inspect each image before adding it to the main README. The OpenGL viewport can render differently across graphics drivers, so confirm that the 3D scene appears in the captured PNG.
